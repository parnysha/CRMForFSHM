1. Упаковываем: mvn clean package
2. Собираем образ:
  docker build -t crmforfshm:0.0.1 .
3. Запускаем на 8080 порту в фоне и изоляции:
  docker run -d -p 8080:8080 -t crmforfshm:0.0.1
4. Проверяем работоспособность:
  curl http://localhost:8080

### API CRM for FSHM

API для работы с CRM-системой для HR-специалистов, с помощью которой они смогут удобно взаимодействовать с информация о сотрудниках
